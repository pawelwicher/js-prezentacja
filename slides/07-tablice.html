Optymalizacja JS — silnik V8

Tablice w V8 — Elements Kinds

PACKED_SMI_ELEMENTS
Wyłącznie SMI (Small Integers) — liczby mieszczące się w 31 bitach
Wartości przechowywane bezpośrednio — brak boxingu na stercie
Najszybszy wariant: operacje arytmetyczne przez CPU bez narzutu
const a = [1, 2, 3] startuje tutaj
PACKED_DOUBLE_ELEMENTS
Przynajmniej jeden element nie jest SMI (np. 3.14, duża liczba całkowita)
Wszystkie elementy jako 64-bitowe double w ciągłym buforze pamięci
Wyzwalane przez a.push(3.14) na tablicy SMI — przejście nieodwracalne
PACKED_ELEMENTS
Stringi, obiekty, mieszanka typów — elementy są referencjami na stercie
TurboFan nie może generować wyspecjalizowanego kodu maszynowego
Wyzwalane przez dodanie nieuzgodnionego typu: a.push("hello")
elements-kinds.js
const a = [1, 2, 3];        // PACKED_SMI_ELEMENTS
a.push(3.14);               // → PACKED_DOUBLE_ELEMENTS  (nieodwracalne)
a.push("hello");            // → PACKED_ELEMENTS         (nieodwracalne)

// Nawet usunięcie stringów nie przywróci poprzedniego stanu:
a.pop();                    // dalej PACKED_ELEMENTS

// Diagnostyka w Node.js z --allow-natives-syntax:
// %DebugPrint([1, 2, 3]);  // elements: PACKED_SMI_ELEMENTS
Packed — zwarty układ
Wszystkie indeksy od 0 do length−1 mają przypisaną wartość
Odczyt dowolnego indeksu jest natychmiastowy — brak sprawdzania istnienia
Tworzony przez literał z wartościami: [1, 2, 3]
TurboFan może wygenerować uproszczony, szybki kod bez gałęzi na brakujące elementy
Holey — tablica z dziurami
Przynajmniej jeden indeks jest "dziurą" — wartość nigdy nieprzypisana
Każdy odczyt wymaga sprawdzenia: czy element istnieje? Jeśli nie — wspięcie po łańcuchu prototypów (Array.prototype, Object.prototype)
Dziura może zwrócić cokolwiek z prototypu — stąd konieczność sprawdzania
Przejście PACKED → HOLEY jest nieodwracalne
holey.js
const a = [1, 2, 3];        // PACKED_SMI_ELEMENTS
a[100] = 4;                 // → HOLEY_SMI_ELEMENTS (indeksy 3–99 to dziury)

const b = new Array(3);     // od razu HOLEY_SMI_ELEMENTS!
                            // Array(n) tworzy tablicę z dziurami

const c = [1, , 3];        // HOLEY_SMI_ELEMENTS — dziura w środku

// delete tworzy dziurę:
const d = [1, 2, 3];       // PACKED_SMI_ELEMENTS
delete d[1];               // → HOLEY_SMI_ELEMENTS — unikaj delete!

// Sprawdź na prototypie co się dzieje z dziurami:
Array.prototype[1] = "z prototypu";
console.log([1, , 3][1]);  // "z prototypu" — dlatego V8 musi sprawdzać!
⚡ Różnica wydajności: w gorącej pętli PACKED_SMI_ELEMENTS potrafi być 2–5× szybsze niż HOLEY_ELEMENTS. SMI nie wymaga boxowania, packed nie sprawdza dziur, jednorodny typ pozwala TurboFanowi generować wyspecjalizowany kod maszynowy.
