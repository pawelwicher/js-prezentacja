Set vs Array — unikalność i wyszukiwanie

ARRAY — upakowane dane w pamięci
Ciągły blok pamięci — elementy leżą jeden za drugim; CPU może je prefetchować, co daje świetną wydajność przy sekwencyjnym dostępie
includes(x) — liniowe przeszukiwanie O(n); musi sprawdzić każdy element po kolei aż znajdzie pasujący
indexOf(x) — tak samo O(n); używany w filter + indexOf do deduplikacji daje O(n²)
Duplikaty — Array przechowuje wszystkie elementy łącznie z powtórzeniami; deduplikacja wymaga dodatkowej pracy
Klucze — tylko indeksy liczbowe; V8 optymalizuje tablice jednorodne (np. same liczby) do kompaktowej reprezentacji C-array
Pamięć — bardzo kompaktowa dla jednorodnych tablic; brak narzutu hash tabeli
SET — hash mapa bez wartości
OrderedHashSet — implementacja identyczna jak Map, ale bez wartości; zachowuje kolejność wstawiania
has(x) — O(1); liczy hash elementu i sprawdza konkretny bucket, niezależnie od rozmiaru zbioru
Unikalność z definicji — new Set(array) automatycznie usuwa duplikaty w jednym przebiegu O(n)
Klucze dowolnego typu — obiekty porównywane przez referencję; liczby i stringi przez SameValueZero
Rozmiar — set.size to O(1), licznik trzymany jako pole
Pamięć — narzut hash tabeli; dla małych kolekcji (< ~100 elementów) Array może być szybszy i lżejszy
BENCHMARK 1 — Sprawdzenie unikalności (has / includes)
✗  Array — includes(x)  O(n)
// 1 000 losowych zapytań, zbiór 100 000;
// część trafia poza zakres → includes skanuje całość
function searchArray(arr, queries) {
  return queries.filter(q => arr.includes(q));
}

searchArray(data, queries);
✓  Set — has(x)  O(1)
// 1 000 losowych zapytań, zbiór 100 000;
// has() to O(1) niezależnie od trafienia
function searchSet(set, queries) {
  return queries.filter(q => set.has(q));
}

BENCHMARK 2 — Deduplikacja zbioru
✗  Array — filter + indexOf  O(n²)
// Deduplikacja tablicy 50 000 elementów
// (połowa to duplikaty)
function dedupArray(arr) {
  return arr.filter(
    (v, i) => arr.indexOf(v) === i
  );
}
✓  Set — [...new Set(arr)]  O(n)
// Deduplikacja tablicy 50 000 elementów
// (połowa to duplikaty)
function dedupSet(arr) {
  return [...new Set(arr)];
}
