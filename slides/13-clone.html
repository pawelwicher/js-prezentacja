Klonowanie obiektów

SPREAD { ...obj }
Głębokość — płytka (shallow); zagnieżdżone obiekty to nadal ta sama referencja
Szybkość — najszybsza metoda; V8 zna kształt obiektu (hidden class) i kopiuje pola bezpośrednio
Prototype — nie kopiuje; wynik ma Object.prototype
Gettery — wywołuje getter, zapisuje wartość (nie kopuje deskryptora)
Kiedy — płaskie obiekty konfiguracyjne, akcje Redux, props
OBJECT.ASSIGN
Głębokość — płytka; semantycznie identyczna ze spreadem dla prostych przypadków
Szybkość — nieznacznie wolniejsza od spreadu; wywołuje wewnętrzny mechanizm przypisania per-klucz
Prototype — nie kopiuje; można scalać wiele źródeł naraz
Gettery — tak samo jak spread: wywołuje i zapisuje wartość
Kiedy — scalanie domyślnych opcji z przekazanymi; migracja starszego kodu
JSON ROUND-TRIP
Głębokość — pełna (deep); serializuje całe drzewo do tekstu i parsuje od nowa
Szybkość — wolna; serializacja + parsowanie + alokacja stringów pośrednich
Ograniczenia — gubi undefined, Date, Map, Set, funkcje, cykliczne referencje → rzuca błąd
Kiedy — nigdy jako pierwsza opcja; tylko gdy masz pewność że dane są serializowalne JSON
STRUCTUREDCLONE
Głębokość — pełna (deep); używa algorytmu Structured Clone z Web API
Szybkość — najwolniejsza; przechodzi przez C++ Web API, obsługuje cykliczne referencje i wiele typów
Obsługuje — Date, Map, Set, ArrayBuffer, cykliczne referencje
Nie obsługuje — funkcji, klas z metodami, Symbol
Kiedy — głęboka kopia złożonych danych; dane z Web Workerów
BENCHMARK 1 — Płytkie klonowanie (spread vs Object.assign vs JSON)
✓  Spread — najszybszy
const clone = { ...obj };
~  Object.assign
const clone = Object.assign({}, obj);
✗  JSON — serializacja do stringa i z powrotem
const clone = JSON.parse(JSON.stringify(obj));
Płaski obiekt z 20 polami, 100 000 powtórzeń.

BENCHMARK 2 — Głębokie klonowanie (JSON vs structuredClone)
✗  JSON — traci typy (Date → string, Map → {})
// Szybsze niż structuredClone, ale gubi typy:
// new Date() staje się stringiem ISO
// new Map() staje się pustym {}
// undefined, Symbol, funkcje znikają
const clone = JSON.parse(JSON.stringify(deep));
✓  structuredClone — zachowuje Date, Map, Set, cykle
// Wolniejsze, ale poprawne semantycznie:
// Date pozostaje Date
// Map pozostaje Map
// cykliczne referencje nie rzucają błędu
const clone = structuredClone(deep);
