stringi

String w V8 to nie zawsze płaski bufor — a + b to para wskaźników (rope), a substring to widok na rodzica. Konkatenacja jest tania, ale widok potrafi uwięzić megabajty.
SeqString
Płaski bufor; Latin-1 = 1 B/znak, jeden „ż" przełącza cały string na 2 B/znak
ConsString (rope)
Wynik a + b — konkatenacja O(1); spłaszczany przy pierwszym odczycie znaku
SlicedString
substring ≥13 znaków = widok: wskaźnik + offset, zero kopiowania
Internalized
Literały i klucze pól: jeden egzemplarz, porównanie wskaźnikiem O(1)
✗ substring więzi rodzica
const file = await resp.text();        // ~10 MB
const header = file.substring(0, 64);  // widok!
cache.set(url, header);
// GC nie zbierze file, dopóki header żyje
// — cache trzyma 10 MB, nie 64 B
✓ wymuś kopię, gdy wycinek ma żyć długo
const file = await resp.text();
// konkatenacja → nowy, niezależny string
const header = ('' + file.substring(0, 64)).slice(0);
cache.set(url, header);                // 64 B
