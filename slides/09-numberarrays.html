Optymalizacja JS — silnik V8

SMI / HeapNumber & Packed / Holey arrays

TYPY ELEMENTÓW — co V8 trzyma w środku
SMI (Small Integer) — liczby całkowite 31-bit; przechowywane bezpośrednio jako wartość, bez alokacji na stercie. Najszybszy typ.
DOUBLE (HeapNumber) — liczby zmiennoprzecinkowe; każda wartość to osobny obiekt na stercie — dodatkowy koszt dostępu i GC
Degradacja jest jednostronna — jeden push(0.5) na tablicy SMI przepisuje ją do DOUBLE. V8 nigdy nie cofa degradacji.
PACKED vs HOLEY — czy są dziury?
Packed — tablica bez dziur; V8 zakłada że każdy indeks ma wartość i generuje szybki, uproszczony kod maszynowy
Holey — tablica z lukami (new Array(N), delete arr[i]); przy każdym dostępie V8 sprawdza czy slot istnieje i szuka w prototypie
Dictionary — bardzo rzadka tablica (duże skoki indeksów); V8 rezygnuje z bufora i używa hash mapy
Unikaj: new Array(N) → użyj Array.from; delete arr[i] → użyj splice
SKĄD NAZWY — HIERARCHIA DEGRADACJI
Nazwy pochodzą z kodu źródłowego V8 — zdefiniowane w src/objects/elements-kind.h. Każda tablica ma wewnętrzne pole ElementsKind — enum z 21 wartościami.
Nazwa składa się z dwóch części: [packed|holey] określa czy są dziury, [smi|double|elements] określa typ wartości.
Hierarchia degradacji — przejście jest zawsze w jedną stronę (w dół), nigdy w górę:
PACKED_SMI_ELEMENTS
  ↓ dodanie float (np. 0.5)
PACKED_DOUBLE_ELEMENTS
  ↓ dodanie obiektu / stringa
PACKED_ELEMENTS
  ↓ dziura (delete / new Array(N))
HOLEY_SMI → HOLEY_DOUBLE → HOLEY_ELEMENTS
JAK ZOBACZYĆ W NODE.JS
Flaga --allow-natives-syntax udostępnia wewnętrzne funkcje V8 z prefiksem %:
// node --allow-natives-syntax script.js

const a = [1, 2, 3];
%DebugPrint(a);
// → elements kind: PACKED_SMI_ELEMENTS

a.push(0.5);
%DebugPrint(a);
// → elements kind: PACKED_DOUBLE_ELEMENTS

delete a[0];
%DebugPrint(a);
// → elements kind: HOLEY_DOUBLE_ELEMENTS
Flaga działa tylko w Node / standalone V8 — niedostępna w przeglądarce. Przydatna do debugowania hot paths.
BENCHMARK — odczyt (for loop), N = 100 000, 50 powtórzeń, średnia
FABRYKA — jak tworzymy każdy wariant
// PACKED_SMI — push samych intów
const a = [];
for (let i = 0; i < N; i++) a.push(i);

// HOLEY_SMI — dziury co 10 elementów
const a = [];
for (let i = 0; i < N; i++) {
  if (i % 10 !== 0) a[i] = i;
}

// DICTIONARY — duże skoki indeksów
const a = [];
for (let i = 0; i < N; i++) a[i * 10] = i;
BENCHMARK — hot path odczytu
// Ta sama funkcja dla każdego wariantu —
// iteracja for + sumowanie elementów
function benchRead(array) {
  let sum = 0;
  const len = array.length;
  for (let i = 0; i < len; i++) {
    const v = array[i];
    if (v !== undefined && v !== null)
      sum += typeof v === 'object' ? v.v : v;
  }
  return sum;
}
