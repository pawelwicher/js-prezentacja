Optymalizacja JS — silnik V8

Map vs Object

OBJECT — zoptymalizowany pod stałą strukturę
Hidden class — V8 buduje ukryty schemat obiektu; dostęp do pola to stały offset w pamięci (jak struct w C)
Inline cache — kompilator zapamiętuje offset klucza; kolejne odczyty pomijają lookup całkowicie
Dictionary mode — po delete lub zbyt wielu zmianach V8 porzuca hidden class i przechodzi na hash mapę — wolniej, bez IC
Klucze — tylko stringi i symbole; obj[{}] → "[object Object]"
Rozmiar — Object.keys(o).length — O(n)
Pamięć — kompaktowy w fast mode; shape współdzielony między obiektami tej samej "klasy"
MAP — zaprojektowany jako słownik od początku
OrderedHashTable — zawsze hash mapa z listą zachowującą kolejność wstawiania; nigdy nie ma "fast mode" obiektowego
Stabilne O(1) — set / get / delete / has zawsze przewidywalne, bez skoków wydajności przy delete
Klucze dowolnego typu — obiekty, liczby, NaN; porównanie przez SameValueZero (jak ===, ale NaN === NaN)
Kolejność wstawiania — [...m.keys()] zawsze w kolejności set(), bez niespodzianek z kluczami numerycznymi
Rozmiar — map.size — O(1), licznik trzymany jako pole
Pamięć — narzut hash tabeli (bucket array, łańcuchy kolizji); dla małych kolekcji Object używa mniej pamięci
BENCHMARK 1 — Częste dodawanie i usuwanie kluczy (rotacja)
✗  Object — delete degraduje do dictionary mode
// Rotacja 20 000 wpisów: dodaj nowy, usuń stary
// delete niszczy hidden class obiektu →
// V8 przełącza go w wolny "dictionary mode"
for (let i = 0; i < N; i++) {
  obj['k' + (N + i)] = i;
  delete obj['k' + i];
  sum += obj['k' + (i + 1)] || 0;
}
✓  Map — zaprojektowany do częstych modyfikacji
// Rotacja 20 000 wpisów: dodaj nowy, usuń stary
// Map zawsze działa jako tablica hashowa —
// set/delete/get są stabilnie O(1)
for (let i = 0; i < N; i++) {
  map.set('k' + (N + i), i);
  map.delete('k' + i);
  sum += map.get('k' + (i + 1)) || 0;
}
20 000 operacji set+delete+get, 300 powtórzeń.

BENCHMARK 2 — Iteracja po kluczach
✗  Object — Object.keys() + pętla
// Iteracja po 50 000 kluczach obiektu
let sum = 0;
const keys = Object.keys(obj);
for (let i = 0; i < keys.length; i++) {
  sum += obj[keys[i]];
}
✓  Map — for...of  natywna iteracja
// Iteracja po 50 000 wpisach Map
let sum = 0;
for (const [, val] of map) {
  sum += val;
}
50 000 kluczy, 500 powtórzeń.
