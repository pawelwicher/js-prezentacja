Map vs Object

Object jest zoptymalizowany pod stałą strukturę (hidden class + inline cache = dostęp jak struct w C). delete i dynamiczne klucze wybijają go do wolnego dictionary mode — Map jest słownikiem z założenia i nie ma skąd spaść.
OBJECT — struct, dopóki go nie zepsujesz
Fast mode — dostęp do pola to stały offset; najszybsza opcja przy stałym zestawie kluczy
delete / dynamiczne klucze → dictionary mode: hash mapa bez IC, bez powrotu
Klucze tylko string/symbol; Object.keys().length to O(n)
MAP — słownik z założenia
Stabilne O(1) — set/get/delete/has bez skoków wydajności
Klucze dowolnego typu, gwarantowana kolejność wstawiania, .size O(1)
Narzut pamięciowy hash tabeli — dla małych, stałych struktur Object lżejszy
benchmark 1 — rotacja kluczy (dodaj nowy, usuń stary)
✗ Object — delete degraduje do dictionary mode
for (let i = 0; i < N; i++) {
  obj['k' + (N + i)] = i;
  delete obj['k' + i];          // ← zabójca hidden class
  sum += obj['k' + (i + 1)] || 0;
}
✓ Map — zaprojektowany do modyfikacji
for (let i = 0; i < N; i++) {
  map.set('k' + (N + i), i);
  map.delete('k' + i);          // zwykła operacja O(1)
  sum += map.get('k' + (i + 1)) || 0;
}
