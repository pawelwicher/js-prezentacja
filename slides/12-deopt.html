deoptymalizacja

TurboFan kompiluje funkcję pod kształty argumentów, które widział. Nowy kształt = złamane założenie = deopt: kod wyrzucony, powrót do interpretera. Megamorfizm to co innego — IC traci specjalizację, ale kod dalej działa.
✓ monomorphic — jeden kształt argumentu
function dist(p) {
  return Math.sqrt(p.x * p.x + p.y * p.y);
}
// zawsze { x, y } → TurboFan specjalizuje:
// stały offset, natywne mnożenie, inlining
✗ megamorphic — kształt-ruletka
dist({ x: 1, y: 1 });          // kształt A
dist({ y: 2, x: 2 });          // B — inna kolejność!
dist({ x: 3, y: 3, z: 0 });    // C
dist({ x: 4, y: 4, label: ''}); // D
dist({ r: 5, x: 5, y: 5 });    // E → IC się poddaje
benchmark — ta sama funkcja, różna liczba kształtów argumentu
500 000 wywołań, 20 powtórzeń — średnia.
