Optymalizacja JS — silnik V8

Liczby w JS

Właściwości standardu
Jeden typ number dla programisty — pod spodem zawsze 64-bitowy double
Bezpieczny zakres całkowity: od -(2⁵³−1) do 2⁵³−1; powyżej pojawiają się „dziury" — 2⁵³ === 2⁵³ + 1 zwraca true
Błędy zaokrągleń: 0.1 + 0.2 === 0.30000000000000004 — ani 0.1, ani 0.2 nie mają skończonej reprezentacji binarnej
Dwa zera: +0 === -0 zwraca true, ale 1/+0 === Infinity a 1/-0 === -Infinity; rozróżnia je Object.is(+0, -0)
Wartości specjalne
NaN — jedyna wartość, dla której x !== x; sprawdzaj przez Number.isNaN(x)
Infinity, -Infinity — wynik przepełnienia lub dzielenia przez zero
Number.EPSILON ≈ 2.22e-16 — najmniejsza różnica między 1 a kolejnym representable double; przydatne przy porównywaniu z tolerancją
Number.MAX_SAFE_INTEGER = 2⁵³−1; Number.MAX_VALUE ≈ 1.79e308; Number.MIN_VALUE ≈ 5e-324 (denormalizowana)
ieee754.js
// Bezpieczny zakres całkowity
console.log(Number.MAX_SAFE_INTEGER);        // 9007199254740991 (2^53 - 1)
console.log(2 ** 53 === 2 ** 53 + 1);        // true — dziura!

// Błąd zaokrąglenia
console.log(0.1 + 0.2);                      // 0.30000000000000004
console.log(0.1 + 0.2 === 0.3);              // false

// NaN
console.log(NaN === NaN);                    // false
console.log(Number.isNaN(NaN));              // true

// Dwa zera
console.log(+0 === -0);                      // true
console.log(Object.is(+0, -0));             // false
Smi — Small Integer
Liczba całkowita upakowana bezpośrednio w słowie wskaźnika — zero alokacji na stercie
Najmłodszy bit = 0 to tag Smi; wartość jest przesunięta o 1 bit w lewo — odczyt to prosty shift arytmetyczny
Na 64-bit V8 z kompresją wskaźników: zakres −2³⁰ do 2³⁰−1; bez kompresji do ±2³¹
Operacje arytmetyczne na Smi są realizowane bezpośrednio przez CPU — brak narzutu boxingu
HeapNumber
Wszystko poza zakresem Smi: liczby zmiennoprzecinkowe, duże całkowite, NaN, Infinity
Alokowany na stercie jako obiekt zawierający 64-bitowy double; słowo wskaźnika trzyma adres z bitem tagu = 1
Tablice: jedna operacja push(0.5) na tablicy PACKED_SMI_ELEMENTS degraduje ją do PACKED_DOUBLE_ELEMENTS — przejście jednokierunkowe
Double field unboxing: gdy hidden class zna typ pola jako Double, wartość jest zapisana inline w obiekcie — brak pośredniego wskaźnika
📐 Elementy Kind: V8 śledzi typ elementów tablicy: PACKED_SMI_ELEMENTS → PACKED_DOUBLE_ELEMENTS → PACKED_ELEMENTS. Każde przejście jest nieodwracalne i obniża wydajność dostępu. Sprawdź aktualny kind przez %DebugPrint(arr) z flagą --allow-natives-syntax.
