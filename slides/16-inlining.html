Inlining funkcji — TurboFan

CO TO JEST INLINING
TurboFan potrafi wbudować ciało małej funkcji bezpośrednio w miejsce wywołania, eliminując koszt call frame, przekazania argumentów i powrotu.
Dzięki temu kompilator widzi połączony kod i może go dalej optymalizować — np. wykryć stałe wyrażenia, usunąć zbędne sprawdzenia typów lub zastosować escape analysis.
Próg budżetu inliningu — V8 zlicza rozmiar funkcji w bytecodes (domyślnie ~600 bajtów). Przekroczenie progu blokuje inlining nawet dla często wywołanych funkcji.
Głębokość rekurencji — inlining jest rekurencyjny, ale ograniczony (domyślnie ~5 poziomów). Zbyt głęboka rekurencja inliningu zwiększa rozmiar kodu maszynowego.
CO BLOKUJE INLINING
Zbyt duże funkcje — funkcja przekraczająca ~600 bajtów bytecode nie zostanie zinlinowana. Wyciągaj krytyczne hot paths do małych helperów.
Obiekt arguments — użycie arguments (nie rest params) blokuje inlining, bo wymaga stworzenia tablicy argumentów.
try/catch wewnątrz funkcji — TurboFan (do niedawna) nie optymalnie obsługuje funkcje z blokami try/catch — wyciągaj je poza hot paths.
Generatory i async — funkcje generatorowe (function*) i async function nie są inlinowane ze względu na skomplikowane zarządzanie stanem.
Megamorphic call sites — wywołanie przez zmienną, która widziała >4 różne funkcje, nie zostanie zinlinowane.

✓  Umożliwia inlining
// 1. Rest params zamiast arguments
function sumArgs(...args) {
  let s = 0;
  for (let i = 0; i < args.length; i++)
    s += args[i];
  return s;
}

// 2. Wyciągnij hot path do małej funkcji
function hotKernel(x) { return x * x + 1; }
function bigCalc(x) {
  // …200 linii…
  return hotKernel(x); // ← to zostanie zinlinowane
}

// 3. Zwykła funkcja — pełna optymalizacja
function makeRange(n) {
  return Array.from({ length: n }, (_, i) => i);
}

REGUŁA KCIUKA
Małe funkcje = dobre
Wyciągaj krytyczne obliczenia do funkcji o jednej odpowiedzialności i <30 liniach. TurboFan sam zadecyduje o inliningu.
Rest params zamiast arguments
(...args) jest traktowany jak zwykła tablica — nie blokuje inliningu. arguments blokuje zawsze.
try/catch poza hot path
Przenieś obsługę błędów na zewnątrz pętli i gorących funkcji. Wewnątrz try/catch TurboFan stosuje ograniczone optymalizacje.
