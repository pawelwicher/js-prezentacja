object pooling

Zamiast tworzyć i porzucać tysiące obiektów na klatkę — alokuj raz, reużywaj w kółko. Zero alokacji w hot path = GC nie ma czego zbierać = znikają pauzy (przy 60 fps jedna pauza GC = zgubiona klatka).
✗ new przy każdej cząsteczce
for (let i = 0; i < count; i++) {
  particles.push({ x: ..., y: ..., vx: ..., vy: ... });
}
// po klatce wszystko staje się śmieciami → GC
✓ pula — acquire / release
class Pool {
  constructor(n) {
    this._p = Array.from({ length: n },
      () => ({ x: 0, y: 0, vx: 0, vy: 0 }));
    this._free = n - 1;
  }
  acquire() { return this._p[this._free--]; }
  release() { this._free++; }
}
// wszystkie obiekty: ten sam kształt → mono IC
