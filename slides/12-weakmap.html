WeakMap, WeakSet, WeakRef

WEAKMAP
Klucze — wyłącznie obiekty (lub symbole non-registered); nie przyjmuje prymitywów
Słabe referencje — klucz nie trzyma obiektu przy życiu; gdy obiekt nie ma innych referencji, GC może go zebrać razem z wpisem
Brak iteracji — nie ma .keys(), .values(), .size — rozmiar jest z definicji nieznany (GC decyduje kiedy)
API — get / set / has / delete
Użycie — prywatne dane powiązane z obiektem, cache bez wycieków pamięci
WEAKSET
Elementy — wyłącznie obiekty; zbiór unikalnych, słabych referencji
Słabe referencje — gdy obiekt znika z reszty kodu, znika też z WeakSet automatycznie
Brak iteracji — nie ma .forEach, .size, [Symbol.iterator]
API — add / has / delete
Użycie — oznaczanie obiektów (odwiedzone węzły grafu, przetworzone żądania) bez ryzyka wycieku
WEAKREF + FINALIZATIONREGISTRY
WeakRef — opakowanie na obiekt; .deref() zwraca obiekt lub undefined jeśli już zebrany
Bez gwarancji czasowych — GC może zebrać obiekt w dowolnym momencie po zniknięciu silnych referencji
FinalizationRegistry — callback wywoływany po zebraniu obiektu; służy do sprzątania zasobów
Uwaga — spec celowo nie gwarantuje kiedy ani czy callback w ogóle zostanie wywołany
Użycie — opcjonalny cache (drogie obliczenia), obserwatory bez strong ref, zarządzanie zasobami zewnętrznymi
BENCHMARK — Map trzyma obiekty przy życiu, WeakMap nie
✗  Map — wyciek: obiekty nie mogą być zebrane przez GC
const cache = new Map();

function processRequest(req) {
  // Map trzyma silną referencję do `req`
  // Nawet gdy caller wyzeruje swoją zmienną,
  // obiekt żyje dopóki cache istnieje → wyciek
  cache.set(req, expensiveCompute(req));
}
✓  WeakMap — brak wycieku: GC zbiera obiekty gdy znikają
const cache = new WeakMap();

function processRequest(req) {
  // WeakMap trzyma słabą referencję do `req`
  // Gdy caller wyzeruje zmienną → GC może
  // zebrać `req` razem z wpisem w cache
  cache.set(req, expensiveCompute(req));
}
Tworzy 10 000 obiektów, usuwa referencje — FinalizationRegistry liczy ile GC zebrał.

KIEDY UŻYWAĆ — reguła kciuka
WeakMap
Dane prywatne lub metadane skojarzone z obiektem spoza Twojej kontroli (DOM node, instancja biblioteki)
WeakSet
Sprawdzanie "czy już przetworzony?" bez trzymania obiektu przy życiu
WeakRef
Cache drugiego poziomu — trzymaj wynik jeśli żyje, odtwórz gdy GC go zbierze

...potrzebujesz iteracji, pewnego rozmiaru lub deterministycznego cyklu życia — użyj Map/Set
